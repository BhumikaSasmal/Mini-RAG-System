# Testing Documents
## sample_policy.txt
A .txt file with a few dummy paragraphs on sample policies include headers and normal text that will be used to test the pipeline's response to .txt files.
## sample_report.pdf
It features the same text from sample_policy.txt but in a machine generated PDF format. This is used to test the pipeline's response to machine generated PDF files.
## sample_scanned.pdf
This file inludes a single page of scanned text from the description of a book. This will be used to test the response of the pipeline to scanned PDFs.
